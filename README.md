A comprehensive, industry-aligned learning roadmap for **C# and the modern .NET ecosystem**. Every topic is organized into its own dedicated folder containing **in-depth theory, Mermaid architecture diagrams, comparison tables, and runnable practical code**.

---

## ⚡ Quickstart

### Build the Solution
```powershell
dotnet build
```

### Run the Interactive Topic Runner
```powershell
dotnet run --project Main
```
*(Enter a topic number from `1` to `26` to run an isolated module, or press **Enter** to run the complete curriculum).*

### Run Automated Unit Tests (xUnit)
```powershell
dotnet test
```
